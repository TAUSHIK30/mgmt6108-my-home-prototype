# My Home basic prototype

MGMT6108 individual My Home contribution: a simplified current-layout reconstruction (A) and proposed redesign (B). This repository contains the runnable app plus AUDIT.md, PROMPTS.md and REFLECTION.md at its root.

Open dist/index.html in a browser. No build or installation needed. A/B variants are accessible with ?v=A and ?v=B. Fictional scenario date: 31 October 2026, Singapore time.

Features: current/proposed toggle, five-change guide, task/date/course filters, required and optional separation, linked Calendar, announcement details, task detail dialog, responsive mobile layout, optional local study flow with consent and debrief. No eLearn account access, submissions, or network data collection.

A is a simplified evidence-informed reconstruction, not an exact copy. Sample activities do not establish real course requirements. Study results are displayed only in the page; refreshing clears the study. Prototype task status is not written to eLearn.

## Deployment

Import this repository into Vercel on the personal Hobby account. Framework preset: Other. Root directory: repository root. Build command: none. Output directory: dist. The included vercel.json declares these settings. No environment variables or dependencies are needed.

Use the production origin with ?v=A and ?v=B for the two versions. Try study mode supplies consent, random allocation, a task, a local timer and a debrief; it does not store or upload research responses. Keep the production and repository URLs available until grades are released.
